# Свадебное онлайн-пригласительное | Парвиз и Самира

Элегантный интерактивный сайт-пригласительное на свадьбу в благородном таджикском стиле: традиционные узоры сюзане, плоды граната (анор), золотое шитье (зардузи), плавная анимация появления элементов, расписание свадебного дня, интерактивный календарь на 29 октября 2026 года с таймером, маршрут в Яндекс.Картах и анкета гостя (RSVP) с сохранением ответов в Google Таблицу.

## 📊 Как подключить Google Таблицу для сбора ответов гостей (за 2 минуты)

1. Откройте [Google Таблицы](https://sheets.google.com) и создайте новую таблицу (например, «Ответы гостей на свадьбу»).
2. В первой строке создайте шапку:  
   | A: Дата и время | B: Имя гостя | C: Присутствие | D: Количество гостей |
3. В меню таблицы выберите: **Расширения** ➔ **Apps Script**.
4. Удалите всё из редактора и вставьте этот код:

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var name = e.parameter.name || "";
  var attendance = e.parameter.attendance || "";
  var guests = e.parameter.guests_count || "0";
  var date = e.parameter.date || new Date().toLocaleString("ru-RU");

  sheet.appendRow([date, name, attendance, guests]);

  return ContentService.createTextOutput("OK").setMimeType(ContentService.MimeType.TEXT);
}
```

5. Нажмите синюю кнопку **Развернуть** (Deploy) в правом верхнем углу ➔ **Новое развертывание** (New deployment).
6. Выберите тип: **Веб-приложение** (Web app).
7. В поле **Кто имеет доступ** (Who has access) выберите: **Все** (Anyone).
8. Нажмите **Развернуть** и скопируйте полученный **URL веб-приложения**.
9. Откройте файл [`wedding-config.js`](wedding-config.js) и вставьте этот URL в поле `googleScriptUrl`:
   ```javascript
   googleScriptUrl: "https://script.google.com/macros/s/ВАШ_ID/exec"
   ```

*Готово! Теперь все ответы гостей будут мгновенно появляться в вашей Google Таблице.*

## 🚀 Как опубликовать сайт на GitHub Pages

1. Загрузите файлы из этой папки в репозиторий на [GitHub](https://github.com).
2. В настройках репозитория откройте **Settings** ➔ **Pages**.
3. Выберите ветку `main` (или `master`) и нажмите **Save**.
4. Сайт будет доступен по адресу `https://ваш-логин.github.io/имя-репозитория/`.
